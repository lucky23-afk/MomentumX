# MomentumX

MomentumX is an AI powered motorsport decision support prototype that helps race teams decide when to use energy for overtaking and when to save it.

## Features

* Attack, Balanced and Save recommendations
* Battery and energy analysis
* Overtake opportunity analysis
* Interactive dashboard
* Simulated race telemetry

## Technology

* Python
* Streamlit
* Pandas
* Plotly
* NumPy

## Run the Project

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py
